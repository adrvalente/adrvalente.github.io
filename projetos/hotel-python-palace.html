Hotel Python Palace

Sistema de gestão hoteleira desenvolvido em Flask com autenticação, reservas, calendário de ocupação e dashboard administrativo.

Resumo

Este projeto foi desenvolvido no âmbito do CET de Tecnologias e Programação de Sistemas de Informação.

Objetivo do Projeto

Desenvolver uma plataforma simples e intuitiva para gerir operações de um hotel.

Tecnologias Utilizadas

Python Flask SQLite HTML5 CSS3 JavaScript Bootstrap OpenPyXL

Principais Funcionalidades

  • Autenticação de clientes e administrador
  • Gestão de reservas
  • Calendário de ocupação
  • Dashboard administrativo
  • CRUD de clientes e reservas
  • Exportação para Excel
  • Proteção de páginas através de sessão
